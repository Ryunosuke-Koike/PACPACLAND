# PACPAC LAND（パクパクランド）

クラシックな横スクロール・アクションへのオマージュとして作った、ブラウザで遊べるゲームです。
HTML / CSS / JavaScript だけで動き、インストールやビルドは不要です。

## 遊び方

`index.html` をブラウザで開くだけで遊べます。

| 操作 | キーボード | 画面ボタン |
| --- | --- | --- |
| 左へ移動 | `←`（または `A`） | ◀ |
| 右へ移動 | `→`（または `D`） | ▶ |
| ジャンプ | `Space`・`Z`・`↑`（または `W`） | JUMP |

ゲーム中の操作は「左・右・ジャンプ」の3つだけです。ジャンプは長く押すほど高く跳べます。
スマホやタブレットでは画面下のボタンで遊べます。

## ストーリー

みかん色のまんまるキャラ「ポッコ」が、まいごの妖精を「ようせいの国」まで送りとどけ、おうちへ帰る冒険です。

1. **STAGE 1 にぎやかタウン**：消火栓と、オバケ「モックン」の運転するクルマに注意
2. **STAGE 2 もりの こみち**：切り株や穴、ホッピングや飛行機に乗ったモックンが登場
3. **STAGE 3 みずうみと やまみち**：動く丸太を渡って湖をこえる
4. **STAGE 4 さばくの ハイウェイ**：サボテンと高速のクルマ。ゴールは「ようせいの国」
5. **STAGE 5 ゆうやけの かえりみち**：お礼にもらった「ウィングブーツ」で空中ジャンプしながら、左へ進んでおうちへ

おうちに着くとラウンドクリア。次のラウンドは敵が速くなります。

## ルール

- モックンにさわるとミス。穴や湖に落ちてもミスです。
- 光る星「パワースター」を取ると、しばらくモックンを食べられます（200 → 400 → 800 → 1600点）。
- フルーツはボーナス点。ジャンプ台に乗ると大ジャンプ。
- 時間切れになると、怒ったモックンが追いかけてきます。
- ゴールすると残りタイムがボーナスになります。ステージの中間を過ぎると、ミスしてもそこから再開できます。
- 20,000点で1UP。ほかにも、どこかに「ひみつ」があるかも…？

## ファイル構成

- `index.html` … ゲーム画面と操作ボタン
- `style.css` … 画面レイアウト
- `game.js` … ゲーム本体（キャラクター・ステージ・効果音もすべてコードで描画／生成）

画像・音声ファイルは使っていません。キャラクター、ステージ、BGM・効果音はすべてオリジナルです。
